# Sprint_7

API-автотесты сервиса «Яндекс.Самокат».

## Технологии

- Java 11
- Maven
- JUnit 5
- RestAssured
- Gson
- Allure

## Проверки

| Класс | Сценарии |
| --- | --- |
| `CourierCreateTest` | Создание курьера, повторная регистрация, занятый логин, отсутствие обязательных полей |
| `CourierLoginTest` | Успешный вход, отсутствие логина или пароля, неверные учётные данные, несуществующий курьер |
| `OrderCreateTest` | Создание заказа с `BLACK`, с `GREY`, с обоими цветами, без поля `color` и с пустым массивом цветов |
| `OrderListTest` | Получение списка заказов |

Тесты независимы. Для регистрации создаются случайные логины и пароли. После тестов курьеры удаляются, а созданные заказы отменяются через API.

## Запуск

Открыть папку `Sprint_7` как Maven-проект в IntelliJ IDEA и выбрать JDK 11.

В терминале из папки проекта:

```bash
mvn clean test
```

Для формирования отчёта Allure:

```bash
mvn allure:report
```

Результаты запуска находятся в `target/allure-results`, HTML-отчёт — в `target/site/allure-maven-plugin`.

Чтобы открыть интерактивный отчёт, можно выполнить:

```bash
mvn allure:serve
```

Для запуска на другом стенде можно указать параметр `-Dbase.url=https://адрес-стенда`.
